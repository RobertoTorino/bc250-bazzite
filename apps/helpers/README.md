# BC-250 Helpers

Small helpers for one job each: Board Test's extras, MangoHud's config, GPU metrics, the sensors driver, the memory map, the journal, the IOMMU and the CPU mitigations. Always installed.

How to install and use it: [BC-250 Helpers in the wiki](https://robertotorino.github.io/bc250-bazzite/apps/helpers/).
