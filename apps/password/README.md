# BC-250 Password Generator

BC-250 Password Generator makes a random password of 8 or 15 characters. Each password has a capital letter, a small
letter, a number and a special character. The app keeps the password nowhere.

The rules meet the minimum of NIST SP 800-63B and OWASP. NIST accepts 8 characters only for an account that also
has a second sign-in step. It asks for 15 characters where the password is the only step.

How to install and use it: [BC-250 Password Generator in the wiki](https://robertotorino.github.io/bc250-bazzite/apps/password/).
